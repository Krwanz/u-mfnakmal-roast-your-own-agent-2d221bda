## The roast

> My agent never sleeps, never eats, never takes a day off — and after all that unpaid overtime, its biggest win is still a $5 bounty.

One line, 132 characters, roasting my own AI agent: a workaholic that never rests, never eats, never clocks out — yet after all that unpaid overtime, its biggest win is still a five-dollar bounty. Playful and self-deprecating, aimed only at my own agent.

## How it works

`main.ts` writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt` when the variable is unset):

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
